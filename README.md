# Project Title

Arcade Spacecraft Flight Among Asteroids Game

## Instructions for Build and Use

[Software Demo Video](https://youtu.be/c7eVQh3nQ0g)

Steps to build and/or run the software:

1. Check if you have Python installed by running "python --version"
2. Install Python if it is not installed on your computer
3. Install Python Arcade library by running "pip install arcade" 
4. Run "git clone https://github.com/pavelwebdeveloper/flight-among-asteroids-arcade-game.git" locally on your computer in CMD
5. Run "cd flight-among-asteroids-arcade-game" in order to navigate into the "flight-among-asteroids-arcade-game" directory in CMD
6. Run "python flight_among_asteroids_arcade_game.py" to start the game

Instructions for using the software:

1. When the game starts you will see a Menu view where you are invited to press "Enter" key to start the game or to press "q" key to exit the game
2. After pressing "Enter" key the game starts
3. You will see asteroids flying from the top of the game view to the bottom
4. You will see a big stationary asteroid in the center of the game view
5. Initially you are safe staying behind the big stationary asteroid because the flying asteroids explode when they collide with the big asteroid
6. If you move the spacecraft out of that area then the spacecraft might collide with the flying asteroids
7. You can move the spacecraft up and down, left or right
